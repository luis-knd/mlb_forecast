# MLB Betting Types

| Category      | Name                     | Abbreviation / Notation | Explanation                                             |
|---------------|--------------------------|-------------------------|---------------------------------------------------------|
| Core          | Moneyline                | ML                      | Bet on which team wins the game, regardless of score.   |
| Core          | Run Line                 | RL                      | Handicap bet, usually ±1.5 runs applied to a team.      |
| Core          | Total Runs Over          | O / Over                | Bet that total runs will be higher than the line.       |
| Core          | Total Runs Under         | U / Under               | Bet that total runs will be lower than the line.        |
| Core          | Team Total Over          | TT O                    | Bet that a specific team scores more than a set number. |
| Core          | Team Total Under         | TT U                    | Bet that a team scores fewer runs than the line.        |
| Core          | Both Teams Score         | BTTS Yes/No             | Bet on whether both teams score at least one run.       |
| First Inning  | No Run First Inning      | NRFI                    | Bet that no runs are scored in the 1st inning.          |
| First Inning  | Yes Run First Inning     | YRFI                    | Bet that at least one run is scored in the 1st inning.  |
| Partial Game  | First 5 Innings Winner   | F5 ML                   | Bet on the winner considering only first 5 innings.     |
| Partial Game  | First 5 Innings Run Line | F5 RL                   | Handicap applied to first 5 innings only.               |
| Partial Game  | First 5 Innings Over     | F5 O                    | Total runs over in first 5 innings.                     |
| Partial Game  | First 5 Innings Under    | F5 U                    | Total runs under in first 5 innings.                    |
| Inning-Based  | Inning Winner            | Inning ML               | Bet on which team wins a specific inning.               |
| Inning-Based  | Run in Inning Yes        | YR Inning X             | Bet that a run occurs in a specific inning.             |
| Inning-Based  | Run in Inning No         | NR Inning X             | Bet that no run occurs in a specific inning.            |
| Inning-Based  | Team to Score in Inning  | Team Score Inning       | Bet on a team scoring in a given inning.                |
| Game Events   | First Team to Score      | First to Score          | Bet on which team scores first.                         |
| Game Events   | Last Team to Score       | Last to Score           | Bet on which team scores last.                          |
| Game Events   | Extra Innings            | Extra Innings Yes/No    | Bet on whether the game goes to extra innings.          |
| Game Events   | Correct Score            | Correct Score           | Predict exact final score.                              |
| Player Props  | Player Hits              | Hit O/U                 | Bet on number of hits by a player.                      |
| Player Props  | Player Home Run          | HR                      | Bet on player hitting a home run.                       |
| Player Props  | Player RBI               | RBI                     | Bet on runs batted in by a player.                      |
| Player Props  | Player Runs Scored       | Run                     | Bet on player scoring a run.                            |
| Player Props  | First Hit Player/Team    | First Hit               | Bet on first hit of the game.                           |
| Player Props  | Last Hit Player/Team     | Last Hit                | Bet on last hit of the game.                            |
| Pitcher Props | Strikeouts               | K O/U                   | Bet on number of strikeouts by pitcher.                 |
| Pitcher Props | Hits Allowed             | Hits Allowed            | Bet on hits allowed by pitcher.                         |
| Pitcher Props | Earned Runs              | ER O/U                  | Bet on earned runs allowed.                             |
| Pitcher Props | Outs Recorded            | Outs                    | Bet on total outs achieved.                             |
